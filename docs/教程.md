# Miniscope 分析软件使用教程

本软件用于分析 UCLA Miniscope V4 单光子钙成像数据，并和动物行为视频做同步分析。
界面左侧是 10 个步骤，从上到下依次完成即可。每个参数下面都有灰色的说明文字。

---

## 0. 安装与启动

**方式一：打包好的程序（推荐给同学使用）**

把 `MiniscopeAnalysis` 文件夹拷到电脑上，双击里面的 `MiniscopeAnalysis.exe`。不需要安装 Python。

Mac（Apple 芯片）：打开 `MiniscopeAnalysis-macOS-arm64.dmg`，把 MiniscopeAnalysis 拖进「应用程序」文件夹（不要在 dmg 窗口里直接打开）。第一次打开前，在「终端」里运行一次：

```
xattr -cr /Applications/MiniscopeAnalysis.app
```

或者先双击一次，被拦下后到 系统设置 → 隐私与安全性 里点「仍要打开」。只需要做这一次，之后打开和软件内更新都不会再弹安全提示。

**方式二：从源代码运行**

1. 安装 Python 3.10 或更新版本（安装时勾选 “Add Python to PATH”）。
2. 下载本仓库，双击 `packaging\install_and_run.bat`。第一次运行会自动安装依赖（约 5 分钟），之后双击就能直接启动。

**对电脑的要求**：普通笔记本即可。所有计算都分块读写硬盘，内存占用一般在 300 MB 到 1 GB 之间。
硬盘需要留出原始视频大小的 1–2 倍空间，用于存放中间结果。

---

## 1. 导入数据

1. 点「选择 Miniscope 文件夹…」，选中 `My_V4_Miniscope` 这一层文件夹，里面有 `0.avi`、`metaData.json` 和 `timeStamps.csv`。
2. 软件会显示帧数、真实帧率、时长，并检查有没有丢帧。
   - V4 设定为 30 Hz 时，实际帧率通常是 29.8 Hz 左右，属于正常现象。软件按时间戳计算真实时间。
3. 点「选择输出文件夹…」，**新建一个空文件夹**。所有结果都保存在这里，原始数据只读、不会被修改。
   - 建议放在本地硬盘，不要放在 OneDrive 等同步盘里（中间文件有几百 MB 到几 GB）。
   - 以后选择同一个输出文件夹，就能接着上次的进度继续分析。

## 2. 预处理

| 参数 | 作用 | 建议 |
| --- | --- | --- |
| 开始 / 结束时间 | 只分析其中一段 | 去掉开头放动物时的几秒 |
| 圈出视野范围 | 拖动黄色圆圈盖住镜头视野，拖动圆圈上的小方块调整大小 | 圆圈外的像素后续会被忽略 |
| 空间降采样 | 2 = 每 2×2 个像素合并成 1 个 | V4 一般用 2 |
| 时间降采样 | 3 = 每 3 帧平均成 1 帧 | 30 Hz 数据可用 1–2；10 Hz 数据用 1 |

完成后看「最大投影」：应该能看到圆形视野、血管，以及一些亮的小圆点（活跃的细胞）。

## 3. 运动校正

动物活动时，脑组织会相对镜头移动。软件以血管等结构为参照，把每一帧对齐到同一个模板。

- 一般直接点「开始运动校正」即可。
- 检查方法：打开「校正前后对比」播放，右边的画面应该基本不再抖动。「位移曲线」显示每一帧移动了多少像素，通常在几个像素以内。
- 如果画面不同部位的移动不一致（例如边缘有扭曲），再勾选「分块非刚性校正」重新运行。

## 4. 去除背景

单光子成像中，焦平面外的荧光形成大片模糊的背景。这一步用比细胞稍大的圆盘做形态学 tophat，去掉比细胞大的结构。

- **细胞直径**是最重要的参数。点「自动估计细胞直径」，软件会在运动校正后的最大投影上测量亮点的大小并填入。也可以自己在「最大投影」上量：空间降采样为 2 时，通常是 6–10 像素。
- 宁可偏小也不要偏大：直径设得太大，挨得很近的两个细胞会被当成一个，细胞数会明显偏少。
- 检查方法：去背景后的「最大投影」上，应该能看到很多清晰、互相分开的亮点。

## 5. 细胞提取

原理（教学用）：
1. **相关图**：一个细胞内部的像素一起变亮、一起变暗，所以它们和相邻像素的时间曲线高度相关。
2. **PNR（峰值噪声比）**：细胞有明显的钙信号峰，噪声区域没有。
3. 两者都高的位置作为候选细胞。接着在每个细胞周围的小区域里，反复优化细胞的形状（A）和活动曲线（C），使「形状 × 活动」尽量还原视频（非负矩阵分解，CNMF-E 的思路）。
4. 两个重叠的候选细胞，如果活动高度相关，就合并为一个。
5. 最后在「视频减去已找到的细胞」的残差里再找一遍，找回挨在亮细胞旁边、第一次被掩盖的暗细胞（同 CNMF-E 的做法）。
6. **宁多勿漏**：人工删除一个假细胞只要点一下，补回一个漏掉的细胞却很难。所以最后还会用放宽的阈值（最小相关和最小 PNR 各乘 0.75）在残差里收集所有剩下的可疑亮点，作为「低置信候选」列出来，已经找到的细胞不受影响。只有明显是邻近细胞残影（活动和旁边细胞几乎一样）、细长条或太小的才直接丢掉。
7. 每个候选有一个 **质量分**（0–100），综合：中心的相关性和 PNR、曲线信噪比、大小、圆度、活动是否只是邻近细胞的回声。在模拟的密集数据上，质量分 ≥ 60 的保留了 99% 以上的真细胞，同时去掉约一半的假候选。

| 参数 | 漏掉细胞时 | 假细胞太多时 |
| --- | --- | --- |
| 最小相关（默认 0.8） | 调低到 0.7 | 调高到 0.85 |
| 最小 PNR（默认 8） | 调低到 5–6 | 调高到 10–12 |

**人工检查**：在「检查细胞」视图里，点击一个细胞，下方会显示它的曲线。

- 绿色 = 保留，红色 = 删除，黄色 = 当前选中，橙色 = 形状可疑（比一般细胞大很多或很长），蓝色虚线 = 低置信候选（质量分低于「质量分阈值」，默认 60），建议逐个检查。
- 推荐流程：勾选「「上一个 / 下一个」按质量分从低到高」，从最可疑的开始看，删掉不像细胞的；看到大部分已经是真细胞时就可以停下。也可以直接点「删除低于阈值的候选」一键删除所有蓝色虚线的候选；删多了点「全部恢复」撤销（会恢复所有被删除的细胞）。
- 选中细胞后，曲线标题里会显示它的质量分。导出的 cells.csv 里也有 quality 一列。
- 「删除 / 恢复所选」：去掉明显不是细胞的（贴在血管上、形状奇怪、曲线只有缓慢漂移）。
- 按住 Ctrl 选中两个细胞后点「合并所选」：用于同一个细胞被拆成两个的情况。
- 「上一个 / 下一个」可以逐个浏览。

判断一个好细胞的标准：形状接近圆形或椭圆形，大小和其他细胞相近；曲线有**快速上升、缓慢下降**的钙瞬变。

**节省硬盘空间**：检查完细胞后，可以点「清理中间文件」，删除预处理后和去背景后的视频（通常各几百 MB 到几 GB）。以后如果要重新运行第 3 或第 5 步，先重新运行第 2 或第 4 步即可。

## 6. 信号与 spike

- **ΔF/F**：细胞荧光相对基线的变化比例。基线 F0 取一段时间窗内（默认 60 秒）的低百分位数，可以抵消缓慢的漂白和漂移。
- **spike 推断**：用 OASIS 算法，根据钙信号上升后按指数衰减的规律，反推出每次放电的时间和大小。
  - 选择所用的钙指示剂（例如 GCaMP6f），软件会自动设定衰减时间。
  - 「spike 阈值」越大越保守，只保留更大的事件。0.5 秒内的连续 spike 合并为一个事件。
  - 「按每个细胞估计衰减时间」（默认勾选）：在指示剂典型值的 0.5–4 倍范围内估计每个细胞的衰减，避免衰减慢的细胞被拆成一串 spike。
- 「导出结果…」生成以下文件：

| 文件 | 内容 |
| --- | --- |
| `dff.csv` | 每列一个细胞的 ΔF/F，第一列为时间（秒） |
| `spikes.csv` | 推断的 spike 大小（0 = 没有 spike） |
| `denoised.csv` | 去噪后的钙信号 |
| `cells.csv` | 细胞编号、位置、面积、信噪比、事件频率 |
| `results.mat` | 以上全部内容和细胞形状，供 MATLAB 使用 |

只导出人工检查时保留的细胞。

## 7. 行为分析

1. 「导入行为视频…」：支持 avi、mp4 等常见格式。
2. **场地**：点「矩形 / 圆形 / 多边形场地」，拖动调整到盒子内部，点「确定」。只在场地内追踪。
3. **区域**（可选）：点「＋矩形区域」等，调整后点「确定」并命名（如 center）。
4. **比例尺**（可选）：点「画比例尺」，把线拖到一条已知长度的边上，填入实际长度（cm），点「确定」。之后速度和路程的单位都是 cm。
5. 设置**僵直**参数后点「开始追踪」。
   - 动作指数 = 相邻两帧间变化的像素占场地的百分比。
   - 动作指数低于「僵直阈值」并持续超过「最短僵直」（常用 1 秒），就算一次僵直。
   - 运行后打开「速度与僵直曲线」，看红色虚线（阈值）是否刚好在动物不动时的动作指数之上。如果不合适，调整阈值后只需重新点一次统计，不必重新追踪（改阈值后点「统计结果」即可）。

**导入其他软件的结果**：
- EthoVision XT：在 EthoVision 里导出 Raw data（txt / csv / xlsx）。软件读取 Trial time、X center、Y center；如果有 Immobile / Freezing 列，一并读取为僵直。
- DeepLabCut：直接选择 DLC 输出的 CSV。

## 8. 同步分析

先把行为视频的时间换算到 miniscope 的时间轴上：

**LED 闪光法（推荐）**：按《LED 同步操作指南》用 Arduino 同时触发 miniscope 和 LED。
1. 点「框选 LED」，把绿色方框放在画面里的 LED 上（不要框到动物）。
2. 填写闪光间隔（和 Arduino 程序一致），有 Arduino 串口记录的话一并选上。
3. 点「计算同步」。软件会报告检测到几次闪光、行为相机的实际帧率等信息。打开「同步检查」，应该能清楚看到开始的长亮、周期性的短闪和结束的长亮。

**手动法**：在行为视频里找到一个已知对应 miniscope 时间的时刻，拖动滑块到这一帧，点「使用当前帧」，填入对应的 miniscope 时间（0 = miniscope 第一帧）。

完成后可以：
- **联合播放**：播放行为视频，下方同时显示平均 ΔF/F 和僵直，黑色竖线表示当前时刻。
- **僵直 vs 运动**：比较每个细胞在僵直时和运动时的平均 ΔF/F，并用循环平移检验判断差异是否显著（双侧 p < 0.05，即每个方向 p < 0.025）。
- **与速度的相关**：每个细胞 ΔF/F 与运动速度的相关系数。
- **事件前后平均**：以僵直开始、进入某个区域，或者手动输入的时间（例如电击时刻）为事件，计算事件前后的平均活动。
- **导出对齐数据**：`aligned_frames.csv`（每个钙成像帧对应的行为数据和所有细胞的 ΔF/F；行为视频没有覆盖的帧，行为列留空），`cell_behavior_stats.csv`（每个细胞的统计结果）。

## 9. 建模分析

完成第 6 步（信号与 spike）后就可以打开。在「选择分析」里选一种，看灰色说明，调好参数后点「运行这项分析」。
每种分析的结果单独保存，换一种分析或关掉软件后再回来都还在。「导出全部建模结果…」会把所有已完成分析的表格（CSV）和一份文字总结写到你选的文件夹。

需要行为数据的分析（GLM、解码器、信息量）要先完成第 7、8 步。其余分析没有行为数据也能运行，有行为数据时会多给出与僵直的比较。

**共同的做法**

- **时间分箱**：先把信号按 0.2–1 秒取平均再分析。钙信号本身变化慢，这样做更快，也更稳。
- **交叉验证**：把记录切成一段一段（每段约 20 秒），用一部分训练模型，在没见过的另一部分上检验。这样得到的 R²、准确率不会因为模型「背答案」而虚高。
- **打乱检验**：把神经活动和行为在时间上错开一个随机的量（循环平移），重复很多次，得到「没有真实关系时」的结果分布。真实结果超过其中 95% 才算显著（p < 0.05）。循环平移保留了钙信号和行为各自缓慢变化的特点，比随机打乱每一帧更严格。
- 细胞很多时，p < 0.05 的细胞里会有一部分是碰巧显著的。结果里同时给出 FDR 校正后的数量，写文章时建议用校正后的结果。

| 分析 | 回答的问题 | 主要结果 |
| --- | --- | --- |
| GLM 编码模型 | 每个细胞的活动能被哪些行为变量解释？ | 每个细胞的交叉验证 R²、各变量的独立贡献和 p 值、事件反应核 |
| 行为解码器 | 群体活动里有没有某个行为的信息？ | 平衡准确率 / AUC（僵直、区域）或相关系数（速度、位置），与打乱结果对比，每个细胞的权重 |
| 细胞组检测 | 哪些细胞经常一起活动？ | 细胞组个数、成员、每组的激活强度曲线、僵直时是否更强 |
| CEBRA 式低维嵌入 | 群体活动在低维空间里长什么样？ | 3 维嵌入、留出数据上的解码结果和打乱标签对照 |
| 隐状态模型 | 群体活动在哪几种「状态」之间切换？ | 每个时刻的状态、转移概率、持续时间、与僵直的重合 |
| 功能连接网络 | 细胞之间的相关构成怎样的网络？ | 度、聚类系数、效率、模块、枢纽细胞、小世界指数；僵直 / 非僵直分别的网络 |
| 互信息与空间信息 | 单个细胞携带多少位置 / 状态信息？ | 空间信息（bits/事件）、位置野、与僵直或区域的互信息及 p 值 |
| 钙事件动力学聚类 | 按钙信号的形状能不能把细胞分成几类（可能的细胞类型）？ | 每个事件的上升时间、衰减 τ、半高宽等；事件和细胞两个层面的类别、稳定性、与信噪比的混杂检查 |

**GLM 编码模型**
- 「事件时间」里可以填电击、声音等时刻（秒，miniscope 时间），用逗号隔开。只填事件、没有行为数据也能运行。
- 「独立贡献」= 去掉这个变量后 R² 下降多少。僵直和速度本身高度相关（僵直时速度为 0），所以两者的独立贡献都可能偏小，这是正常现象：它只算「别的变量替代不了的部分」。
- 「事件反应核」显示每个细胞在事件（或僵直开始）前后的反应形状。

**行为解码器**
- 僵直时间太少（< 2%）或太多（> 98%）时无法解码。
- 平衡准确率 0.5 相当于瞎猜。不要只看数值高低，要看它是否明显超过打乱后的分布。
- 「细胞权重图」里红色细胞活动升高时倾向判为该行为，蓝色相反。

**细胞组检测**
- 细胞组数量默认自动判断。数据很短或细胞很少时可能一个都找不到。
- 要比较训练和提取两天的细胞组是否重新激活，用第 10 步「跨天配准」里的「细胞组重激活」。

**CEBRA 式低维嵌入**
- 这是软件内置的轻量实现（小型神经网络 + InfoNCE 对比损失），思路与 CEBRA 相同，但不是官方软件包，网络更小，结果不会完全一样。适合教学和快速查看。
- 发表用的结果建议用官方 CEBRA：点「导出给官方 CEBRA…」，得到 `cebra_input.npz` 和 `run_cebra.py`，在装了 `cebra` 的 Python 环境里运行即可。
- 判断嵌入是否可信，看留出数据的解码结果是否明显高于「打乱标签对照」，而不是只看图好不好看。

**隐状态模型（HMM / AR-HMM / rSLDS）**
- 先用 HMM、3–5 个状态。想看每个状态内部的动力学再换 AR-HMM。
- 循环 AR-HMM 是 rSLDS 的简化版：完整的 rSLDS 同时推断连续潜变量，这里直接用主成分当作连续潜变量，其余（每个状态一套线性动力学、切换概率依赖当前位置）相同。
- 「比较状态数」给出留出数据的似然。似然通常随状态数一直缓慢上升，选开始变平的那个点，而不是最大值。
- 状态是模型自己找的，编号没有含义；结果说明里会告诉你哪个状态和僵直重合。

**功能连接网络**
- 相关不等于突触连接，只表示两个细胞的活动同步。
- 「超过打乱水平」适合看单只动物的网络；比较不同动物或不同天时，建议改用「固定连接密度」，否则边数不同会影响几乎所有图论指标。
- 网络很稀疏、大部分细胞不连通时，不报告小世界指数。

**互信息与空间信息**
- 恐惧条件化里动物僵直时停在一个位置不动，僵直相关的细胞会因此显得有「位置选择性」。想排除这一点，把「最低速度」设为大于 0（例如 2 cm/s），只用动物在移动的时刻计算空间信息。
- 场地小（恐惧箱）时空间格子数用 6–10。

**钙事件动力学聚类（细胞分型）**

不需要行为数据。思路：不同类型的神经元（例如兴奋性 / 抑制性，快放电 / 慢放电）钙事件的形状和发放方式可能不同，先测量每一个钙事件的动力学参数，再看它们是否自然地分成几类。

1. **检测事件**：在轻度平滑的 ΔF/F 上找峰。峰值要比细胞的静息水平、也比事件前的低谷高出「事件阈值」倍噪声（默认 3 倍）。
2. **测量参数**（每个事件）：振幅、上升时间（10%→90%）、最大上升速度、半衰减时间、衰减时间常数 τ（峰值之后的单指数拟合）、半高宽、面积、与上一个事件的间隔。
   这些都直接从信号上量出来，**不用**第 6 步 OASIS 模型里的衰减值（那个值是模型假设，很多细胞会被拟合得偏长）。
3. **孤立事件**：前面的基线已经回落、衰减在下一个事件之前降到 20% 以下的事件。叠加在一起的事件衰减测不准，默认只用孤立事件，并要求衰减拟合 R² ≥ 0.5。
4. **两个层面的聚类**：
   - 事件层面：每个事件是一个点。
   - 细胞层面：每个细胞取自己事件参数的中位数，再加上事件频率和爆发性（B = (σ−μ)/(σ+μ)，−1 规律、0 随机、接近 1 成簇）。事件少于「每个细胞最少事件」的细胞不参加。
   参数先取对数、标准化，再用高斯混合模型分 1–6 类，用 ICL（或 BIC）自动选类别数。**1 类也是可能的答案**，表示没有分得开的亚群。

**怎么判断结果可不可信**（结果说明里会自动给出结论）

- **稳定性**：随机重抽样 50 次重新分类，与原分类的一致性（ARI）≥ 0.8、每一类的 Jaccard ≥ 0.6 才算稳定。不稳定的分类换一批数据就会变。
- **轮廓系数**：≥ 0.25 说明各类分得比较开；稳定但轮廓系数低，更像连续变化而不是截然不同的类型。
- **事件类别和细胞有没有关系**：如果事件类别只是同一类事件的「典型」和「拖尾」（例如叠加事件、信噪比低的事件），每个细胞都会同时有几类事件。软件比较「每个细胞的事件有多大比例属于它最主要的一类」与随机打乱的结果；ICC 表示某个参数的差异有多少来自细胞之间（越接近 1 越像细胞固有属性）。
- **信噪比混杂**：信号弱的细胞，噪声会让上升和衰减显得更慢。若各类细胞的信噪比明显不同、或衰减 τ 与信噪比高度相关，类别可能只是「亮的细胞」和「暗的细胞」。「信噪比混杂检查」图可以直接看到这一点。

**重要提醒**：单光子 GCaMP 的钙信号是很多动作电位经过指示剂、表达量、背景和离焦模糊之后的结果，动力学差异不一定来自细胞类型。这里得到的类别只能作为假设，需要用形态、分子标记（例如 Cre 小鼠、免疫染色）或光遗传标记等独立方法验证。振幅和面积默认不参与聚类，因为它们主要反映表达量。

**结果**
- 事件聚类散点 / 细胞聚类散点：标准化参数的前两个主成分，下方是各类别数的 ICL / BIC 曲线。
- 各类事件平均波形：上方是按类别排列的单个事件波形（已按峰值归一化），下方是每类的平均波形。
- 细胞图：细胞在视野里的位置，按细胞类别着色；下方是每类细胞的平均事件波形。
- 导出（「导出全部建模结果…」）：`kinetics_events.csv`（每个事件的参数和类别）、`kinetics_cells.csv`（每个细胞的中位参数、频率、爆发性、类别和各事件类别的比例）、`kinetics_clusters.csv`（每类的数量、稳定性和参数中位数）、`kinetics_cluster_waveforms.csv`（各类平均波形）。

## 10. 跨天细胞配准

同一只动物不同天（例如条件化训练日和第二天的场景测试）分别做完第 1–6 步后，用这一步把两天的细胞对应起来。
每一天都有自己的输出文件夹；这一步只读取它们，结果保存到另外一个空文件夹。

**操作**

1. 打开任意一天的输出文件夹，进入第 10 步。当前这一天会自动出现在表格里。
2. 点「添加…」，依次选择其它几天的输出文件夹。在「名称」一栏改成好记的名字，例如 Day1 训练、Day2 测试。第一行是参考 session，其它 session 都对齐到它；用「上移」「下移」调整。
3. 选一个空的「结果文件夹」，点「开始配准」。几百个细胞、3 天的数据一般在一分钟内完成。
4. 看结果：
   - **对齐后叠加图**：品红是参考 session 的细胞，绿色是另一天的细胞，重合的地方是白色。对齐好时大多数细胞是白色。「对齐前叠加图」可以对比对齐的效果，「叠加显示」选择和哪一天比较。
   - **配准的细胞**：每个点是一个细胞，颜色表示它在几天里找到。
   - **匹配模型**：每个点是两天之间的一对候选细胞。红色（距离近、形状像）判为同一个细胞，蓝色判为不同细胞。两团点分得越开，配准越可靠。
   - 右侧文字给出每天之间匹配的细胞数，以及模型估计的误配和漏配数。

**参数**

- **对齐依据**：默认用「细胞形状图」（所有细胞叠在一起），与 CellReg 相同。如果两天找到的细胞差别很大，可以改用「平均投影」，靠血管等结构对齐。
- **变换方式**：重新安装镜头后视野通常会平移和轻微旋转，用默认的「刚性」即可。只有对齐后边缘仍有错位时才选「非刚性」。
- **最大距离**：0 = 自动（细胞直径的 1.5 倍）。中心距离超过它的两个细胞不会被配对。
- **匹配阈值**：默认 0.5。想更严格（宁可漏掉也不配错）可以提高到 0.7–0.8。
- 各天预处理时的「空间降采样」必须相同。裁剪的位置和大小可以不同，软件会按裁剪位置先粗对齐。

**跨天分析**（需要相关的几天都完成第 6 步）

- **细胞组重激活**：在「模板」session 里用 PCA + ICA（或 NMF）找细胞组，只使用两天都配准上的细胞；再用同样的权重计算这些细胞组在「目标」session 里的激活强度。检验时打乱目标 session 里的细胞身份（每个细胞的活动不变，只是不再知道谁是谁），真实的平均激活强度超过打乱结果的 95% 即为显著重激活。session 带同步好的僵直数据时，还会给出哪个细胞组在僵直时更强。
- **跨天活动稳定性**：所有追踪到的细胞在每天的事件率、两天之间事件率的相关，以及每天的细胞在其它天里找到的比例。带僵直数据时，比较两天的「僵直时更活跃」细胞是不是同一批（超几何检验：重叠数明显高于随机期望，说明是同一群细胞在编码恐惧记忆）。
- 「导出表格（CSV）…」：`cell_registration.csv`（每行一个细胞，各列是它在每天的细胞编号，空 = 那天没找到）以及跨天分析的表格。

**注意**

- 一天里没找到某个细胞，不一定是它不活动，也可能是那天它太暗、没被提取出来。比较「细胞是否在某天出现」时要谨慎。
- 「对齐相似度」低于 0.3 时会给出提示：可能视野变化很大，或者选错了动物，请先看叠加图。

## 常见问题

**提示“没有找到符合条件的细胞”**
降低「最小相关」或「最小 PNR」；检查「细胞直径」是否和实际差得很多。

**很多假细胞落在血管上**
提高「最小 PNR」；在人工检查里删除；也可以检查运动校正是否充分。

**追踪时动物丢失**
确认场地范围画对了；在「动物颜色」里手动选择深色或浅色；光线不均匀时尽量让场地照明均匀。

**同步时找不到开始标记**
LED 框选位置不对，或者行为视频是在触发之后才开始录制的。行为视频应该比 miniscope 先开始录。

**检查更新**
打包好的程序启动时会自动检查有没有新版本（每天最多一次），有的话会弹出更新说明，点「立即更新」即可。小版本只下载几百 KB，重新打开软件就生效；需要更新整个程序时，软件会自动下载、关闭并重新打开。都不需要手动下载安装包。新同学第一次安装时，从 GitHub 的 Release 页面下载最新的正式版本（x.y.10 之后的大版本 x.(y+1).0 才发布正式版本，例如 v0.3.0）。也可以在菜单「帮助 → 检查更新…」手动检查。分析结果保存在输出文件夹里，更新不会影响它们。

**程序运行中想停止**
点右下角的「取消」。已完成的步骤不受影响。

## 第 11 步　行为与空间专题

完成信号提取、行为追踪和同步后，打开「行为与空间专题」。空间分析需预先画好场地。每次运行生成独立的 HTML 报告、CSV 和 JSON，保存在项目的 `behavior_studies` 文件夹。

- **僵直起始与解除**。设置事件窗口和普通停顿速度上限。程序按位置、速度及减速幅度匹配停顿，在同步视频中可回放每个匹配事件。至少三对事件时，逐对留出测量分类准确率。
- **跨天位置解码**。选择同一动物的配准结果，确认场地及摄像机朝向一致。查看跨天中位误差，并与相同细胞、相同测试帧的日内结果比较。误差使用按场地宽、高归一化的坐标。
- **目标移位**。每行填写一个阶段的钙记录开始秒数和目标中心 X、Y，坐标与行为轨迹一致。存在目标移位且有共同采样时，用其他位置的阶段训练，在留出阶段比较位置与目标距离模型的均方误差。仅有单一目标位置时提供描述性图表。
- **距墙调谐**。按到最近边界的距离显示平均 ΔF/F 和停留时间，可分别查看接近、远离和沿墙运动。先核对各箱的停留时间，再比较细胞活动。

在新生成的专题报告中选择分组、图宽和格式，然后点击「导出当前图」或「导出整版」。目标移位和距墙专题在细胞分组中提供组合图。SVG 和 300 dpi 尺寸的 PNG 与同名 CSV、JSON 一起下载为 ZIP。PDF 使用浏览器的「另存为 PDF」，同时下载包含 SVG 和作图数据的 ZIP。旧报告可用原参数重跑生成新版。

### 追踪质量与按试次分析

在「行为分析」查看追踪质量色带。原始观测表示该时刻有可用坐标。夹在两次有效观测之间的短缺口可以插值，默认上限 0.5 秒，设为 0 可关闭。首尾缺失和超限缺口保留为缺失。点击色带可检查对应视频。旧项目重算行为统计和下游分析时会使用当前设置，之前导出的报告保留原结果。

为一只动物的一次记录准备 UTF-8 CSV。时间单位是秒，使用钙记录时钟；缺失的事件时间留空。试次编号在同一张表内必须唯一。

```csv
animal_id,trial_id,cue_s,outcome_s,outcome
Mouse01,011,25.0,27.4,reward
Mouse01,012,50.0,,omission
```

在「行为与空间专题 → 按试次分析」选择 CSV、对齐事件、窗口、行顺序和保留的细胞。点击热图中的某行会定位对应的同步行为视频。行详情分别显示神经信号覆盖率、原始追踪比例、插值比例、无效及同步范围外的比例。只有钙信号时也能分析，追踪质量留空。原始追踪比例指窗口中有坐标原始观测的比例。

早期、晚期按试次时间各取一半，奇数时保留中间试次并单独标记。只有神经窗口完整的试次参与早晚期平均。打开专题报告可导出热图、曲线和组合图；每次运行的文件夹还保存逐试次表以及针对所选细胞的逐时间点 CSV 和 JSON。

### 视频处理与细胞提取的 GPU 计算设备

「运动校正」「去除背景」「细胞提取」都有「计算设备」选项。「自动选择」会在 Apple M 系列 Mac 上测试 Metal，在 NVIDIA 设备上测试 CUDA。软件用浮点运算和 FFT 检查设备能否计算，多个 CUDA 设备通过时优先选择检测时可用显存最多的设备。也可以手动指定后端和显卡。点「检测 / 刷新显卡」可查看实际型号；Apple 设备显示统一内存容量。每一步完成后，页面和项目记录都会给出实际使用的后端、设备及回退原因。

| 步骤 | GPU 处理的部分 |
| --- | --- |
| 运动校正 | 支持刚性和分块校正。Metal 在 GPU 上计算归一化互功率谱和逆 FFT；正向 FFT 沿用 CPU 的数值路径，以保留弱纹理图像的配准精度。CUDA 批量执行正、逆 FFT。重采样使用 OpenCV。 |
| 去除背景 | 中值滤波、圆盘腐蚀与膨胀、白顶帽背景相减，逐批处理。 |
| 细胞提取 | 局部相关图的邻域统计、初始足迹的像素与种子曲线乘积、HALS 时间活动更新及空间足迹更新中的局部乘积。种子筛选、轮廓连通性、合并及质量评分继续由 CPU 处理。 |

第 5 步是 CalciLume 自研的简化 CNMF-E。它用相关图和 PNR 播种，在已去背景的视频上拟合局部空间足迹、活动曲线和逐像素常量基线。原始 CNMF-E 在拟合过程中估计随时间变化的环形邻域背景。第 6 步另行计算 ΔF/F 和 OASIS 反卷积。选择计算设备会沿用相同的种子阈值、更新顺序及质量规则。[原始 CNMF-E 论文](https://elifesciences.org/articles/28728)

遇到显存不足或支持的 GPU 运行错误时，软件用 CPU 重新计算，并显示原因；取消任务会保留该步骤上一次成功生成的结果。

