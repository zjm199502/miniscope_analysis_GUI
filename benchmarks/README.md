# CalciLume 细胞提取基准

基线为 CalciLume 0.4.0。24 次合成实验由 3 个固定种子和 8 种条件组成，另用一段带公开人工掩膜的真实单光子录制复核。每次运行都经过正式背景去除和细胞提取入口。

## 结果

三种子合计。每格依次为命中数 / 候选数。质量筛选后重新进行一对一匹配。

| 条件 | 参考细胞数 | 全部候选 | 质量 ≥ 60 |
|---|---:|---:|---:|
| 纯背景，含缓慢漂移和纹理 | 0 | 0 / 0 | 0 / 0 |
| 强信号 | 12 | 12 / 27 | 12 / 14 |
| 弱信号，荧光幅度从 40 降为 7 | 12 | 12 / 26 | 12 / 13 |
| 邻近细胞，最近两者间隔 7 像素 | 12 | 12 / 29 | 12 / 16 |
| 两段已知刚性位移 | 12 | 12 / 60 | 12 / 21 |
| GUI 合成录制，默认提取参数 | 9 | 6 / 289 | 6 / 276 |
| 同一录制，相关阈值 0.6、PNR 阈值 4 | 9 | 6 / 524 | 6 / 277 |
| 同样宽松的阈值，采用已知的零位移 | 9 | 9 / 522 | 2 / 2 |
| 真实录制 TUnCaT，单视野 | 81 | 47 / 60 | 44 / 51 |

**历史案例。** 在种子 0 的 GUI 宽松设置中，172 个候选有 3 个匹配、0 个近邻重复、169 个落在容差以外。其中 135 个偏离目标的候选来自常规或残差种子，34 个来自额外低置信搜索。提高质量门槛至 60 后仍保留 91 个候选。种子 0 的输入没有运动，算法却估计出中位 13.64 像素、最大 28.28 像素的位移。改用已知零位移后，仍检出 173 个候选，但全部低于质量门槛。种子 1、2 也表现出类似的数量膨胀。应分别调查低纹理视野中的错误配准、种子产生和质量分数，单独关闭运动校正不能解决候选过多的问题。

**真实录制。** 使用按文件名排序的首个 TUnCaT 样本 c25_123_348（50×50 像素、6000 帧、20 Hz），以及同名的 81 个参考掩膜。全部候选的中心匹配精确率为 78.3%，召回率为 58.0%；质量 ≥ 60 时分别为 86.3% 和 54.3%。更严格的轮廓匹配（每个提取足迹按自身峰值的 20% 二值化，IoU ≥ 0.5）两组均为 31 个命中。一个小视野不足以支持全局修改阈值。参考数据与掩膜来自 [Bao 等的公开数据](https://doi.org/10.6084/m9.figshare.22304569)，见[对应论文](https://doi.org/10.1038/s42003-024-06668-7)。

## 方法

- 五种基础合成条件使用同一带结构背景的模拟器，600 帧、96×96 像素、10 Hz。三个 GUI 条件共享相同的 V4 测试视频，各 600 帧、30 Hz，空间和时间降采样均为 1。
- 一对一匹配先最大化 3 像素内的配对数，再最小化匹配距离。重复指未匹配但靠近参考中心的额外候选，偏离目标指其不靠近任一参考中心。精确率分母为候选数，召回率分母为参考细胞数；分母为零时留空。重复分类仅表示空间近邻关系。
- 合成参考中心平移到校正后的参考坐标，偏移量为施加位移与软件校正位移之和的逐轴中位数。配准随时间失稳时，单一参考中心只能近似代表运动轨迹。
- 真实样本使用全部帧，将 16 位电影按全片最小值和最大值线性映射至 0–255，保留浮点精度。在发布数据的原始坐标系评估背景去除和提取，跳过再次配准。人工掩膜只用于评分。中心匹配与轮廓匹配分别计算。
- 图中展示种子 0 和真实样本。metrics.csv 含所有种子与阈值，locations.csv 含逐候选及逐参考坐标、分类和候选来源。

## 复跑

在仓库根目录运行。制图需 matplotlib，读取公开录像需 h5py。

~~~powershell
python -m pip install -e ".[dev]" matplotlib h5py
python benchmarks/extraction.py --out benchmarks/results --tuncat-dir "D:/data/data_TUnCaT"
~~~

从上方 Figshare 下载含录像的 data_TUnCaT.zip（文件 ID 49636131）。指定目录下应有 c25_123_348.h5 和 GT Masks/FinalMasks_c25_123_348.mat。省略 --tuncat-dir 时只跑合成部分，可用 --seeds 指定复现种子。原始电影及中间工作区不写入仓库。
